# PCE-Agencia — Sol y Playa Tours

MVP funcional de una aplicación web para gestión de una agencia de viajes.

## Ejecutar
1. Descomprime el proyecto.
2. Abre `index.html` en un navegador moderno.
3. Usuario demo: `admin`
4. Contraseña demo: `admin123`

## Incluye
- Login y sesión demo.
- Dashboard con indicadores.
- CRUD básico de clientes, reservas, proveedores, servicios, itinerarios, transacciones y facturas.
- Eliminación de registros.
- Exportación CSV.
- Persistencia local con LocalStorage.
- Diseño responsive.
- Reportes financieros básicos.
- Moneda RD$.

## Próxima etapa recomendada
Para producción: backend, base de datos SQL, autenticación real, roles/permisos, API de mapas, disponibilidad real de vuelos/hoteles, pasarela de pagos, generación PDF de facturas, auditoría, copias de seguridad y despliegue.
